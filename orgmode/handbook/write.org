#+title: Remember is a speech act.
#+options: toc:nil num:nil

[[file:index.org][Back to the field]]

=ljos remember= POSTs one lesson to =/v1/atoms=. =ljos prefer= POSTs one preference. The process must already have =PACKSET_URL=. =packset ensure= starts the writer and prints the URL. It does not export the URL into the next process.

The workspace is the git remote of the current directory (=git:github.com/org/repo=). Search is GET =/v1/search= on that workspace. It does not open a deed. A transcript is not a source. If you did not say =Remember:= or =Prefer:=, the pack did not change.

If =packset status= says up and remember hangs or returns 400, the writer is wedged. =packset stop=, then =packset ensure=. Do not dump the sitting into a card.
