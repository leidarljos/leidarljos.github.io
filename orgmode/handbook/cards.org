#+title: Overflow is an error.
#+options: toc:nil num:nil

[[file:index.org][Back to the field]]

=ljos cards= prints =USER.md= and =MEMORY.md= from =--dir= (default =.=). A missing file prints nothing. The command never creates those files and never writes them.

Cards answer one question: what did the human freeze? Overflow is an error, not a prompt to dump more. A client scrapbook is not a card.

Read the cards at the start of a sitting. If they are empty, leave them empty.
