How-to

Task-shaped. One harness per heading. ljos-mcp must be on PATH.

Grok

[mcp_servers.ljos]
command = "ljos-mcp"
args = []
startup_timeout_sec = 30

Put that in ~/.grok/config.toml. Restart Grok. The skill still names the five habitats; the MCP is the seat.

Claude

claude mcp add ljos -- ljos-mcp

Codex

codex mcp add ljos -- ljos-mcp

Cursor

{
  "mcpServers": {
    "ljos": { "command": "ljos-mcp" }
  }
}

Pi

Add ljos-mcp to the MCP server list the same way you add any stdio server. Restart the session.

Cite a deed on a ticket

ljos evidence deed-…
ljos deed <id> --add deed-…
ljos recall <id>

Citation is not a merge. Completing a session node does not close the ticket.

Check argv without reloading a pack

ljos policy -- ls -la

The TCB is the policy daemon. Reloading a pack is not a check.

Settle agreement

ljos consensus <id>

That is DeGroot / the ODE crate, then the tracker verb. It is not a vote count.
