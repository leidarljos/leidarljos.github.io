claimdag

CAS claim and complete on a DAG. The host process is the sole mutator; the snapshot is unpacked Cap'n work.bin.

Install

cli 
cargo install --git https://github.com/leidarljos/claimdag claimdag-cli

Pass --dir DIR, or set CLAIMDAG_DIR. Otherwise the runtime directory holds work.bin.

Commands

From claimdag --help. Default list is live work only.

CommandDoes
claimdag upsert --summary TEXT Create or update a node. Omit --id to mint.
claimdag list Live work, newest first.
claimdag list --json --all Every node, including archived terminals, as JSON.
claimdag get ID Print one node by 32-hex id.
claimdag claim ID --assignee ACTOR Compare-and-swap claim. Omit --gen to ignore generation.
claimdag complete ID Mark the node terminal (default status done). Does not close a ticket.
claimdag renew ID The holder is still working. Moves the lease without changing hands.
claimdag reclaim --lease 900 Hand back every claim quiet longer than the lease, in seconds.
claimdag link PARENT CHILD Add a boolean hard dependency (parent before child).
claimdag unlink PARENT CHILD Drop a boolean hard dependency. A missing edge is ok.
claimdag archive ID Soft-hide a terminal node. Not a delete. unarchive clears the flag.

complete --status is done, failed, or cancelled. Pass the --gen from claim to be refused if the lease was reclaimed while the work was in flight.

Alone, or through ljos

Use claimdag when a host is handing out this sitting: mint nodes, link dependencies, renew or reclaim a lease, list the graph. The snapshot is capped and prunes finished work. It is not a record, and it has no field for a deed accession.

Use ljos when the seat should claim or complete and leave the rest of the graph to this crate. ljos claim and ljos complete exec the same verbs. Completing a node does not close a ticket.
