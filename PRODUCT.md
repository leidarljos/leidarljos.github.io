# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

A person who keeps a seat on their own machine. They arrive to write one claim and search that claim back.

## Product Purpose

The site teaches that visit. Success is a visitor who leaves with the install lines, one sitting, and the same claim returned by search.

## Positioning

One written claim is the unit. Search returns that text. The ticket stays open until the tracker closes it.

## Operating Context

The landing page persuades the visitor to write one claim. The docs and the handbook are for reading. Docs walk the first write. The handbook is republished from org templates, so its chrome is the template chrome.

## Capabilities and Constraints

Static pages. One stylesheet, `site.css`. The handbook HTML is generated from `orgmode/handbook` through `org/templates`. Root paths such as `/start/` redirect into `/docs/` and stay redirects.

The public pages keep the brand leiðarljós, the heading “Write one claim. Search it back.”, the sitting specimen, the install lines, and the LongMemEval figures `0.949` and `0.549 / 0.634`.

## Brand Commitments

The name is leiðarljós. The visual system already on the pages stays: ink, cream, and gold, with Source Serif 4, Source Sans 3, and IBM Plex Mono.

## Evidence on Hand

The landing page states recall@5 `0.949` and QA / ceiling `0.549 / 0.634` for the fused arm. Those figures are not to be rewritten. No further measurements are invented here.

## Product Principles

- One claim, written on purpose, then searched back.
- The landing asks for that write. Docs and the handbook explain it.
- The handbook republish keeps the same nav and the same stylesheet.
- Numbers on the page stay the numbers that were measured.
