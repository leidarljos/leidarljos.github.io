1. Install

$ curl -fsSLO https://github.com/leidarljos/ljos/releases/latest/download/install.sh && sh install.sh

The script fetches ljos, packset, vissue, deedar, claimdag, ljos-policyd and ljos-consensus from their GitHub releases into ~/.local/bin and checks each checksum. Read it first: it is scripts/install.sh. To build from source instead, cargo install --locked ljos packset vissue-cli vissue-mcp deedar-cli claimdag-cli ljos-policyd ljos-consensus. Other runners: Harnesses.

Work starts as a ticket. vissue q -p PROJECT "TITLE" mints it in the tracker VISSUE_ROOT names, and ljos sitting claims it. That tracker is yours. A ticket filed on one machine is invisible to every other install until VISSUE_ROOT is a git checkout those machines share. The sit page uses a scratch tracker under /tmp so a first run does not touch a live one.

2. Write one claim, then retrieve it

$ ljos remember "the default fuse is CombMNZ"
8e3e7827...  lesson  due 2026-10-10T21:56:09.549Z  the default fuse is CombMNZ
$ ljos search fuse
Score is how the scorers ranked this query. ...
1.0000  3/3  lesson  8e3e7827...  today  the default fuse is CombMNZ

ljos remember starts the writer when none is answering. PACKSET_URL=off is the one way to have no pack. A URL pointed somewhere else is not replaced.

3. The clock

$ ljos due
0 due; 1 scheduled, next at ...

Search shows kind lesson and the same sentence. A review is scheduled a day out. Tomorrow ljos due lists the claim. ljos graded ID (or --lapsed) moves the clock.

4. Prefer is the same path

$ ljos prefer "never extract on write"
$ ljos search extract
Score is how the scorers ranked this query. ...
2.0000  3/3  preference  fe9d4d04...  today  never extract on write
1.0000  1/3  lesson      8e3e7827...  today  the default fuse is CombMNZ

The fraction is how many of the scorers named the hit. Neither number says whether the claim is true.
