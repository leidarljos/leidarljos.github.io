  search
  ...

2. Remember without a pack fails

$ ljos remember "the default fuse is CombMNZ"
Error: PACKSET_URL unset; remember/prefer POST /v1/atoms

packset ensure prints the URL. It does not export it into your shell.

$ packset ensure
PACKSET_URL=http://127.0.0.1:8761
$ export PACKSET_URL=http://127.0.0.1:8761

3. One explicit write, then retrieve

$ ljos remember "the default fuse is CombMNZ"

  "level": "explicit",
  "text": "the default fuse is CombMNZ",
  "id": "156eb2be-9898-46d8-bb2d-ce0dec1706b1",
  ...

$ ljos search fuse
1.0000  lesson  156eb2be-…  the default fuse is CombMNZ

4. Prefer is the same path, different kind

$ ljos prefer "never extract on write"
preference  01f2e067-…  never extract on write
$ ljos search write
1.0000  preference  01f2e067-…  never extract on write

5. Cards print files. They do not write them

$ ljos cards --dir /tmp/demo
--- /tmp/demo/USER.md ---
# User
I write Remember: only.
--- /tmp/demo/MEMORY.md ---
# Memory
Overflow is an error.

With no files in the directory, the command prints nothing and exits 0.
