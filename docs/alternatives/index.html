Where ljos fits among agent memory tools

Mem0, Zep and Letta let a model decide what to keep. A CLAUDE.md file is the exception, and you write it by hand. ljos keeps only what you tell it to keep. That one choice explains most of the table below, including where ljos is behind.

Which to pick

Mem0, Graphiti and Letta suit memory that builds itself from conversations, with a model doing the extraction. A CLAUDE.md or AGENTS.md file is enough when one page of standing notes covers it. A plain retrieval index over your documents answers questions about those documents. ljos fits when each memory should be a sentence someone chose to write, kept in local files and searched back per prompt, next to a rule check on shell commands and a ticket tracker.

Where ljos is behind

  • Retrieval accuracy. On LongMemEval_S session retrieval the lexical arm reaches recall@5 0.914 and the fused arm 0.949. rohitg00/agentmemory reports 91.7% for its BM25 component on the same measure over the 470 answerable questions, so the lexical arms are level. The lexical arm scores 0.568 on MemoryAgentBench accurate retrieval, below the published BM25 row of 0.605 (that row used GPT-4o-mini as the reader; ours used a local 7 B model). The measured rows and where the data is.
  • Changing facts. Graphiti keeps a validity window on every fact. ljos closes an earlier lesson only when a new one opens with the same words, and scores 0.395 on MemoryAgentBench conflict resolution at 262K tokens. The measured row and where the data is.
  • Question answering. Those scores come from a local 7 B reader. Its answer accuracy on LongMemEval_S is 0.549 against a 0.634 ceiling for perfect sessions. JordanMcCann/agentmemory reports 96.20% with a hosted reader and judge on the oracle file, whose history holds only the evidence sessions, so its neighbour is the 0.634 ceiling; we have not run a hosted model.
  • It forgets what nobody said. Answers can only use what was written, and nothing is extracted from the conversation. If you never say Remember:, the next session starts without it. That is the point, and it is also a cost.

What we think is new

The parts all have neighbours: hybrid retrieval, review schedules, ticket trackers, command filters. What we have not found elsewhere is the combination with provenance kept on every write: memory written only by declaration, no model in the write path, lessons an agent drafts held until you accept them, and artefacts recorded as hashed deeds the tracker cites.

Tools that build memory from transcripts can be poisoned by text that reaches the transcript: MINJA does it with ordinary queries, and InjecMEM with an email a compromised tool returns. Writing only on declaration should resist that. We have not yet measured it; that test is the next piece of work, and the results will go on the compare page when they exist.
