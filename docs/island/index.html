How it is built

The pack links each claim to the claims it shares names with. Those links form clusters. ljos island TASK takes the top search hits as seeds and spreads activation two hops: half lost per hop, divided by fan-out. The cluster comes back strongest first. That is spreading activation over a semantic network (Collins and Loftus, doi:10.1037/0033-295X.82.6.407). Fig. 1 folds sentence vectors (bge-small, cosine as --dot, Ceriotti asinh at the median pairwise scale). Fig. 2 folds the weighted link graph. Gold is the docs activation cluster, not a 3-gram hash.

How use shapes it

When the seat uses an island, ljos island --fire moves each fired pair's weight toward one and fades the rest (Hebb with Oja's term). The next cue like this one walks a heavier path. The weights travel in a handover.

What it is not

It is not the search ranking. On LongMemEval the island lost as a ranker (hit@1 0.377 against the fused panel's 0.889). Activation flows to hubs. The island is orientation and what fires together after use, not the order the hits come in.
