CLI and MCP

ljos is the seat. Habitats keep their own CLIs. Completing a session node does not close a ticket.

CLI

VerbHabitatDoes
ljos sitting IDseatOpen: doctor, cards, due, island, recall, timeline, claim.
ljos finish IDseatClose: remember, fire, complete, learn. Does not close the ticket.
ljos remember TEXTpacksetPOST one explicit claim. Needs PACKSET_URL.
ljos prefer TEXTpacksetSame write path, kind preference.
ljos search QUERYpacksetRetrieve standing knowledge.
ljos evidence ACCESSIONdeedarFrozen product bytes.
ljos current ACCESSIONdeedarCurrent pointer.
ljos deed ID [--add ACCESSION]trackerCite. Not a merge. Crate: vissue.
ljos recall IDtrackerWorking set.
ljos vote ID [--for CHOICE]trackerBallots.
ljos claim NODEclaimdagThis-session CAS.
ljos complete NODEclaimdagDoes not close a ticket.
ljos cardscardsRead USER.md / MEMORY.md. Never writes.
ljos policy -- ARGVpolicydArgv law. Does not reload a pack.
ljos consensus IDconsensus crateDeGroot / ODE, then the tracker verb.

ljos-mcp execs ljos. Tool names match the verbs, including ljos_vote.
