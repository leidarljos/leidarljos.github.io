Standing memory / packset

What does this seat know, standing?

install
cargo install --git https://github.com/leidarljos/packset packset-cli packset-daemon

Write and retrieve

  1. packset remember TEXT

    One lesson, two sentences at most. Never mined from a transcript.

  2. packset prefer TEXT

    One standing choice. Same write path, kind preference.

  3. packset search QUERY

    Fuse a prefix-and-edit scan, BM25+, and a dense ballot when an encoder is present.

  4. packset due

    What the review clock wants back.

  5. packset island CUE

    The cluster a task activates.

  6. packset ensure

    Start packsetd and print PACKSET_URL.
