leiðarljós Tutorial How-to Reference Explain

First session

One explicit write. One retrieve. Cards stay unread-write. Fifteen minutes.

1. Install the seat

cargo install --git https://github.com/leidarljos/ljos
cargo install --git https://github.com/leidarljos/consensus
ljos --help

2. Write one claim, on purpose

Standing knowledge is only written when you say so. There is no extract-on-write.

export PACKSET_URL=http://127.0.0.1:8761
packset ensure
ljos remember "the default fuse is CombMNZ"
ljos search fuse

3. Read the cards. Do not write them

ljos cards

USER.md and MEMORY.md are a human freeze. Overflow is an error. The harness memory file is dead.

4. Wire one harness

Pick the line for your client on the how-to. Restart that client. Ask it to ljos search fuse.

5. Leave the other habitats alone until you need them

A deed, a claim, a policy check, and consensus each have a verb. You do not need them for the first write.
