Notes from using the seat

Written after running the binaries on this machine. Not a manifesto.

PACKSET_URL is not in the environment after ensure

packset ensure printed PACKSET_URL=http://127.0.0.1:8761. The next ljos remember still failed until the URL was exported by hand. The tutorial starts there because that is the first thing that happened.

Remember returns a lesson. Prefer returns a preference

Both POST /v1/atoms with level: explicit. Search printed a score, the kind, the id, and the text. The workspace on the atom was the git remote of the directory the command was run from.

Cards are silent when the files are missing

ljos cards in /tmp printed nothing. With USER.md and MEMORY.md present, it printed those two files and stopped. It did not create them.

deedar and claimdag do not invent a store

ljos evidence failed: no DEEDAR_URL and no store under ~/.local/share/deedar/store. claimdag list in an empty directory said there is no work.bin and that claiming creates it. The seat does not paper over that.

Consensus without a trust graph is 50/50 in one round

Two ballots, no edges, ljos-consensus settle returned shares 0.5 / 0.5, rounds: 1, engine: degroot-fj. That is the discrete stepper. The Seldon C API is a separate path (SELDON_SRC / --seldon).

policy prints argv

ljos policy -- echo hi printed a warning and then echo hi. It did not run the command and it did not reload a pack.

Citation is not a merge

That sentence is still the law. It is not a substitute for the commands above working on your machine.
