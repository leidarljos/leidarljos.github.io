Completing is not closing.

Back to the field

ljos sitting ISSUE --assignee NAME opens the sitting: doctor, cards, due, island, recall, timeline, claim, in that order, stopping at the first store that does not answer. The assignee is a name; it maps to one actor. One live claim per name. A second claim is refused with the issue the name still holds and the two verbs that free it: ljos complete finishes it, ljos release hands it back unfinished. ljos finish ISSUE --lesson "..." [--outcome OPTION] closes the sitting: remember, fire the island, complete, learn. A later sitting on the same issue reopens its node and takes it; the ledger keeps the earlier completion.

Completing a node does not close a ticket. The tracker is the graph. Create and claim tickets through vissue. Never hand-edit issues.org. Crate docs: vissue.rgoswami.me.

File before you speak. An audit with no ids is unfinished work. A leftover that does not fit this sitting is a child ticket, then the original work continues.
