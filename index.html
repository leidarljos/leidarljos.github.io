One identifier. Four questions.

      
The pin is an accession: deed-… or sha256:. The pack names it. The tracker cites it. The deed store answers for the bytes.

      

        

          
Name, do not paste

          
A store holds a citation, not a copy of another store. Opening the bytes is a deed question.

        

        

          
Write is explicit

          
Remember: and Prefer: are the pack. Cards stay frozen. Extract-on-write is refused.

        

        

          
Session is not the ledger

          
claim / complete hand out this sitting. Completing a node leaves the cited ticket open.

        

      

    


    

      
Five habitats. Two that are not stores.

      
ljos is the seat. Each habitat keeps its own writer. policyd is argv law. consensus is a model, not a habitat.

      

        

          
Habitat · human · frozen

          
cards

          
USER.md and MEMORY.md are the working core a person froze. Read-only. Never extract-on-write.

          
Writer: the human. Lifetime: the sitting they froze.

Habitat · frozen product

Habitat · graph

          
vissue

          
What does this node stand on, and who agrees? The tracker is the ledger. A deed citation, not a paste.

          
Write: graph. Completing elsewhere does not close a ticket.

        

        

          
Habitat · this session

          
claimdag

          
What is this session handing out? CAS claim and complete on a DAG. The host is the sole mutator.

          
Write: claim / complete. Completing does not close a ticket.

        

        

          
Argv law · not a store

          
policyd

          
The pack is argv only. It is not a ledger, not a log, and not a stamp book. Reload is not a ritual.

          
ljos policy -- <argv> checks the line. It does not own the TCB.

        

        

          
Model · not a store

          
consensus

          
DeGroot / Friedkin–Johnsen over a trust graph. Seldon is the ODE engine. This crate does not link it.

          
ljos consensus calls here first. --seldon execs seldon when it is on PATH.

        

      

    


    

      
Install

      
The seat and the model. Then one line per harness. Other projects may still speak one habitat alone.

      

        

          

            seat
            
          

          
cargo install --git https://github.com/leidarljos/ljos

        

        

          

            model
            
          

          
cargo install --git https://github.com/leidarljos/consensus
